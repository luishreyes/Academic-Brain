# concepts

Una página por keyword. Son los nodos que conectan notas distintas en el grafo.
`/ingest` las crea y mantiene: cuando una nota usa un concepto, agrega el backlink
bajo "Notas que usan este concepto".

Cada página puede tener, opcionalmente, una sección **"Qué dice la literatura"**:
una síntesis narrativa de lo que las notas del concepto dicen en conjunto. Es de
esfuerzo alto y no se autogenera. Ver `../guias/03-keywords-y-conceptos.md`.
