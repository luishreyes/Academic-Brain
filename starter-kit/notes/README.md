# notes

Las notas del vault, una por fuente, en tres subcarpetas según el tipo:

- `papers/` — publicaciones académicas (`type: paper`)
- `articles/` — artículos periodísticos, ensayos, divulgación (`type: article`)
- `books/` — libros (`type: book`)

El formato exacto de cada tipo está en `../CLAUDE.md` y en `../templates/`. Las
notas las crea el comando `/ingest`; rara vez se escriben a mano. Nombre de
archivo: `AAAA-MM-DD_slug-corto.md`.
